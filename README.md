# CalCounter AI

Here's the complete tech stack used in calcounterAI app:

Frontend & Framework
Next.js 15.3.3 (React metaframework with SSR/SSG, Turbopack for fast dev builds)
React 18.3.1 (UI library)
React DOM 18.3.1
TypeScript 5 (type-safe JavaScript)
UI Components & Styling
Tailwind CSS 3.4.1 (utility-first CSS framework)
Radix UI (16 component libraries including accordion, dialog, dropdown, tabs, etc.)
React components for accessible, unstyled design system
Lucide React 0.475.0 (icon library)
Tailwind Merge 3.0.1 (merge Tailwind classes without conflicts)
Tailwind CSS Animate 1.0.7 (animation utilities)
Forms & Validation
React Hook Form 7.54.2 (efficient form management)
@hookform/resolvers 4.1.3 (validation schema adapters)
Zod 3.24.2 (TypeScript-first schema validation)
Data & Charts
Recharts 2.15.1 (React charting library)
Embla Carousel 8.6.0 (carousel/slider component)
Date-fns 3.6.0 (date manipulation & formatting)
React Day Picker 8.10.1 (calendar UI)
AI & Backend
Genkit 1.20.0 (Google's AI framework)
@genkit-ai/google-genai 1.20.0 (Google Gemini AI integration)
@genkit-ai/next 1.20.0 (Genkit integration for Next.js)
Genkit CLI 1.20.0 (dev tools)
Backend & Database
Firebase 11.9.1 (authentication, Firestore DB, realtime features)
Utilities
dotenv 16.5.0 (environment variable management)
clsx 2.1.1 (className utility)
class-variance-authority 0.7.1 (variant-based styling system)
patch-package 8.0.0 (patch npm dependencies)
Development Tools
PostCSS 8 (CSS processing)
TypeScript Types (@types/node, @types/react, @types/react-dom)
ESLint (linting, configured via Next.js)
Build & Development
Turbopack (Next.js fast bundler, used in dev mode)
Next.js App Router (file-based routing)
Summary: Modern full-stack web app with React + Next.js, Tailwind styling, Genkit + Gemini AI for intelligent features, Firebase backend, and comprehensive form/validation stack.
